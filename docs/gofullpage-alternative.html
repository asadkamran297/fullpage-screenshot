GoFullPage alternative: what happened, and what to use instead

Written by the developer of Full Page Screenshot, one of the alternatives listed below. The comparison is deliberately honest about where this extension is the weaker choice.

What happened to GoFullPage

Around 10–11 August 2026, GoFullPage — the roughly 11-million-user extension that had been the default answer to "full page screenshot" for years — was removed from the Chrome Web Store. According to the developer's own statement, this is a copyright dispute over a 34-pixel animated GIF, not a security problem, and they are working with Google to get the listing restored.

The removal also tripped Chrome's automated safety machinery, so many users saw the browser flag the extension as unsafe and disable it. That is why a working install suddenly stopped working.

Is GoFullPage unsafe?

There is no public evidence of a security issue. The "unsafe" warning is what Chrome shows for any extension removed from the store, whatever the reason for removal.

Will it come back?

Probably. The dispute is over content, not code, and the developer says they are working with Google on it. If you can wait, waiting is a reasonable choice.

Can I keep using my existing install?

If Chrome has disabled it, you can re-enable a disabled extension from chrome://extensions, but Chrome will keep warning you and it will not receive updates while it is delisted. That is a decision to make with your eyes open, not a recommendation.

The alternatives, compared honestly

Chrome's built-in capture No install at all. Free Buried in DevTools: open DevTools, Ctrl+Shift+P, "Capture full size screenshot". Fails on many complex pages.

Where Full Page Screenshot fits

If what you used GoFullPage for was "click the button, get the whole page, save or paste it", this extension does that same job and adds two things GoFullPage charges for or does not do: multi-page PDF export at no cost, and automatic clipboard copy of every capture.

It is also open source under the MIT licence and makes zero network requests, with no host permissions requested. If the delisting made you think harder about what your extensions can see, that is the part worth checking — the source is public, so the claim is verifiable rather than something you have to take on trust.

Where it is not the right pick: if you relied on GoFullPage for capturing a scrollable panel inside a page (Gmail threads, Notion, embedded documents), for annotating captures, or for region and delayed capture, this extension does not do those yet. Awesome Screenshot or FireShot will serve you better today.
